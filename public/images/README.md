# Imágenes para la pantalla de código

Sube estas imágenes **con exactamente estos nombres**:

- `plaid-background.png`: fondo de cuadros rosados (ideal: 1920 × 1080 px o mayor; se usa con cover).
- `success-character.png`: perrito/mascota feliz del popup correcto, preferiblemente PNG transparente.
- `error-character.png`: perrito/mascota triste del popup incorrecto, preferiblemente PNG transparente.

La aplicación funciona sin estas imágenes gracias al fondo CSS y a los emojis de prueba. Una vez subidas, las rutas públicas serán `/digital-gifts/images/...` en GitHub Pages.

El código de demostración es **0720**, editable en `src/App.tsx`. No protege contenido confidencial.
