# Fotos de los recuerdos de Hetto

Guarda seis imágenes en esta carpeta, con los nombres exactos:

- recuerdo-1.jpeg
- recuerdo-2.jpeg
- recuerdo-3.jpeg
- recuerdo-4.jpeg
- recuerdo-5.jpeg
- recuerdo-6.jpeg

Se recomienda exportar a JPEG (mínimo 900 px de ancho), con encuadre centrado. Las fotos se adaptan a los marcos con `object-fit: cover`.

La galería se muestra automáticamente una vez que Hetto llega al final de la carta. Las imágenes faltantes muestran una tarjeta de marcador de posición. Puedes cambiar el orden de las fotos renombrando los archivos.
